# CleanBoard

**CleanBoard** is a bold Web3 advertising platform built for the *Cleanverse* hackathon, designed to transform digital billboard auctions into a fast, transparent, and decentralized experience on the **Monad Testnet**.

## 🚀 Project Vision & Summary

- **CleanBoard** redefines decentralized advertising by combining real-time bidding with blockchain trust.
- It delivers a sleek **auction-driven billboard marketplace** where advertisers connect wallets, compete for placements, and launch campaigns without middlemen.
- Built for the **Monad network**, our platform prioritizes speed, transparency, and the confidence of on-chain settlement.

## 💡 How It Works?

1. **Connect Wallet**
   - Users link their Web3 wallet to unlock the platform and reveal active bid cards.

2. **Join Auctions on Monad Testnet**
   - Advertisers participate in dynamic bidding for premium ad placements using an intuitive auction interface.

3. **Upload Creative via Drag & Drop**
   - After winning, the advertiser uploads the ad creative with a simple **drag & drop** interaction, streamlining campaign launch.

4. **Live Simulation Preview**
   - The uploaded creative instantly appears in a **live simulation** view, showing how the ad would look within a news or blog site layout.

## 🛠️ Tech Stack

- **Frontend:** *Next.js* + *Tailwind CSS*
- **Blockchain:** **Monad Testnet** for smart auction coordination and wallet-based authentication
- Focused on clean, modular code with responsive design and a polished user experience.

## ⚡ Local Setup & Installation

To run the project locally, use the following commands:

```bash
npm install
npm run dev
```

- Open your browser at `http://localhost:3000`
- Connect a wallet to activate the bidding experience
